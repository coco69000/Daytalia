# Cloud Functions Daytalia

Ce sous-projet contient les notifications serveur pour :

- Memories (ce jour-là)
- Post populaire chez les amis
- Recommandations d'amis

## Installation

```bash
cd functions
npm install
```

## Variables OneSignal

Configurer deux secrets Firebase :

- `ONESIGNAL_APP_ID`
- `ONESIGNAL_REST_API_KEY`

## Build

```bash
npm run build
```

## Déploiement

```bash
npm run deploy
```
